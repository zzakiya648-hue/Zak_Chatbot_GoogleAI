# Zak_Chatbot_GoogleAI
A google AI Chatbot using python

## How to Setup and Run

1. **Clone the repository:**
   Download or clone this project folder to your local machine.

2. **Get your API Key:**
   Go to [Google AI Studio](https://google.com) and generate a free API key.

3. **Add your Key:**
   Open the `chatbot.py` file and replace `"YOUR_GEMINI_API_KEY_HERE"` with your actual key string.

4. **Install Requirements:**
   Run the following command in your terminal to ensure you have the required web library:
   ```bash
   pip install requests
   ```

5. **Run the Chatbot:**
   Launch the script using Python:
   ```bash
   python chatbot.py
   ```
   Type your message and press Enter. Type `quit` to end the conversation.
